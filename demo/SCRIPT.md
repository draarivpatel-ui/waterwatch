# WaterWatch demo video

Narrated 1080p walkthrough of the post-revamp UI: the SDG 6 clean-water
equity lab, the mixture and sensitivity lab, advisory honesty behavior and
the English/Spanish toggle. Everything below is produced locally and
repeatably; no API keys, no signed-in browser, no account of any kind.

## Files

| File | Role |
| --- | --- |
| `demo/narration.txt` | Voiceover source. One sentence per line, blank line between paragraphs. |
| `demo/steps.json` | The drive plan. `at` steps pin actions to narration marks (`"mark": "2.1"` = paragraph 2 sentence 1, resolved through `timing.json`). |
| `demo/timing.json` | Measured per-sentence start/duration from the synthesized audio. Regenerated by `synth`. |
| `demo/narration.wav` | Assembled voiceover (macOS `say`, voice Samantha, 170 wpm, 24 kHz mono). |
| `demo/captions.ass` | Lower-third captions burned into the video (white on a translucent dark box). |
| `demo/waterwatch-demo.srt` | Companion captions file for upload forms. |
| `demo/waterwatch-demo.mp4` | The finished video. |
| `demo/test-proof.txt` | Live verification transcript captured in the same run as the video. |
| `demo/proof.html` | The on-screen verification card rendered from that transcript; the drive ends on it. |
| `scripts/record-demo.mjs` | The whole pipeline: `synth`, `capture`, `check`, `all`. |
| `scripts/serve.mjs` | Zero-dependency static server used by `capture`. |

## Reproduce

```bash
npm run demo:synth     # narration.txt -> narration.wav + timing.json + captions
npm run demo:capture   # verify, then serve + headless Chrome drive -> demo/waterwatch-demo.mp4
npm run demo:check     # ffprobe + volumedetect report
```

`capture` first re-runs the real checks (`node --test test/`,
`node scripts/sdg6-audit.mjs`, and the station honesty harness when present),
writes `test-proof.txt` and `proof.html` from that output, and refuses to
record unless all of them are green. It then starts `scripts/serve.mjs` on an
ephemeral port, drives the app in a throwaway headless Chrome (empty
profile, remote debugging port 0, real mouse and key events, a visible drawn
cursor, downloads denied), resamples the screencast to a constant 30 fps,
muxes the narration and burns the captions in one ffmpeg pass (`h264`
`yuv420p` `color_range=tv` `+faststart`, `aac`). All temp files live in
`WATERWATCH_DEMO_TMP` (or a fresh `/tmp/waterwatch-l96-*` dir) and are
deleted on exit. It aborts if the page ever navigates off the demo origin.

## Honesty note

The video is an honest capture of this repo running in a plain browser with
zero network requests. Every number narrated is computed by the page during
the drive: lead 24.6 vs 3.1 ppb, Hazard Index 1.27, nitrate 13.6 to 17.0
under 20 percent evaporation, and the SDG 6 plan figures all come from the
bundled synthetic presets, which the UI labels as synthetic. Where an
advisory is active the filter table still shows scenario numbers but the
SDG 6 planner withholds every contaminant-fit claim; the narration
describes exactly that split. The `695` test count, `56` audit checks and
`0` honesty findings are the live outputs captured into `test-proof.txt`
seconds before recording started.
