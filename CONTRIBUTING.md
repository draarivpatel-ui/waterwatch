# Contributing to waterwatch

Thanks for your interest in contributing. This project is released under the
MIT license; by submitting a contribution you agree that it is licensed under
the same terms.

## How to contribute

1. Fork the repository and create a branch from `main`.
2. Make your changes. Keep them focused; unrelated refactors belong in a
   separate pull request.
3. Run the test suite before submitting:

   ```sh
   npm test
   ```

4. Open a pull request against `main` describing what changed and why.

## Guidelines

* Follow the existing code style and project conventions.
* Keep documentation in sync with behavior changes.
* Do not commit secrets, credentials, personal data, or generated build output.
* Text files must not contain em dashes or en dashes; use plain hyphens.
* Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting bugs and requesting features

Use GitHub Issues at https://github.com/draarivpatel-ui/waterwatch/issues.

For security issues, do not open a public issue. Follow the private reporting
process in [SECURITY.md](SECURITY.md) instead.
