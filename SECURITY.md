# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately through GitHub's private vulnerability reporting:

https://github.com/draarivpatel-ui/waterwatch/security/advisories/new

Please do not open a public issue for security reports, and do not include
exploit details in public discussions. For general questions or non-sensitive
bugs, open a regular issue at
https://github.com/draarivpatel-ui/waterwatch/issues.

We will acknowledge your report as soon as possible, keep you informed of the
progress toward a fix, and coordinate disclosure with you.
